# SmartTask – Android Task Management App

## Project Overview
SmartTask is an Android task management application built using Kotlin and Jetpack Compose. It helps users create, manage, update, and track their daily tasks.

## Tech Stack
- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- Hilt – Dependency Injection
- Room Database
- Retrofit
- Kotlin Coroutines & Flow
- WorkManager
- Android Notifications
- JUnit & MockK – Unit Testing

## Architecture
UI → ViewModel → Repository → Data Sources

Data Sources:
- Room Database for local storage
- Retrofit API for remote operations

## Key Features
- Create, edit and delete tasks
- Task
